# Abdullah Al Mahi · Portfolio

Personal website of Abdullah Al Mahi, final-year EECE undergraduate at MIST, Dhaka.

Live: https://abdullahalmahi526.github.io

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole site: HTML, CSS and JavaScript in one file |
| `portrait.webp` | Hero portrait (background removed) |
| `VTOL.jpg` *(optional)* | Upload a photo with this name and it replaces the drawn VTOL on the project card |
| `cv.pdf` *(optional)* | Upload a CV with this name and "Download CV" buttons appear |

## Updating

1. Open this repository, click **Add file → Upload files**.
2. Drop the new `index.html` (or `VTOL.jpg`, `cv.pdf`).
3. Click **Commit changes**, wait 1–10 minutes, then hard-refresh the site (Ctrl + F5).
